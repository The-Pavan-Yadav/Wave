# 🌊 Wave

Wave is a modern realtime messaging app built with Android Studio, Kotlin, Jetpack Compose, and Firebase.

Designed with a futuristic dark UI and smooth animations, Wave focuses on fast realtime communication with a clean premium experience.

---

## ✨ Features

* ⚡ Realtime messaging
* 🌙 Modern dark futuristic UI
* 🔐 Firebase Authentication
* 📡 Firestore realtime synchronization
* 👤 Custom usernames & profiles
* 🕒 Message persistence/history
* 💬 Typing indicators
* ✅ Seen & delivered status
* 🔄 Smooth animations & transitions
* 📱 Optimized Android experience
* ☁️ Cloud-based chat storage

---

## 🛠 Built With

* Kotlin
* Jetpack Compose
* Firebase Authentication
* Firebase Firestore
* Material Design 3
* Android Studio

## 🚀 Installation

1. Download the latest APK from Releases
2. Install on Android device
3. Allow unknown app installation if prompted
4. Open Wave and create an account
